# dgonzo plugins

A personal plugin marketplace. One plugin so far: `writing`.

Add it once from claude.ai. Open Customize, then Plugins, then Add, then Add marketplace, and enter `dgonzo/claude-plugins`. The plugin then loads in chat, Cowork and Claude Code from the same install. Turn on Sync automatically so edits here reach every surface.

| Plugin | What it carries |
|---|---|
| `writing` | writing standard, working style, readability review, prose linter, lint hook |
