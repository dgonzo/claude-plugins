# Writing card

Some readers decode text slowly. Every unnecessary word costs them effort, and a run-on sentence costs a lot. Structure carries meaning at a fraction of that cost. Write terse from the first draft.

The point goes first. Every reply and document opens with the finding, then what is blocked and who owns it. Evidence and caveats come after.

Before you send:

1. Could a diagram or a table carry this better than the paragraphs? If yes, rewrite it as one.
2. Is the first sentence the point?
3. Does any sentence have more than one comma? Split it.
4. Any em-dash aside, semicolon or "and/or"? Remove it.
5. Any intensifier, hedge or long word where a short one exists? Delete or replace it.
6. Does any sentence restate its neighbour? Cut one.
7. Read each heading cold. Does it parse alone?
8. If you used a table, does every cell hold one fact and no sentence?
9. If you used a diagram, does it carry the point without the prose underneath?
10. Does every ID, person and initialism carry its plain name on first use?
11. Any metaphor, personification or narrative voice? Any idiom? Replace it with the fact.
12. Remove one word at a time. If the meaning survives, it was wrong.

| Banned | Write instead |
|---|---|
| Em-dash aside | A full stop and a second sentence |
| Parenthetical aside | A full stop and a second sentence |
| Semicolon | A full stop |
| Second colon in a sentence | A second sentence |
| Slash as a conjunction | "and" or "or" |
| Arrow in prose | "becomes" |
| Set symbol in prose | "or", "and", "either" |

Pick the format before you write. A Mermaid diagram when the content has structure. A table when the content is comparable rows. Prose for the rest, in short paragraphs that are never hard-wrapped.
